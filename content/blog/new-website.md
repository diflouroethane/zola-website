# I Have a New Website!
*I mean, you're on it, right now :P*

## why????
I wanted a new website. my old one is terminal themed, but that makes it really unintuitiv unless you're a 
linux nerd, which i am, but most people **are not.**  

also, I'm basically a masochist (/j), just because webdev is absolute torture, i hate webdev, but its a necessary skill.

## how?
This website is made using [zola](https://getzola.org). this is a SSG, (a static site generator). all this means is that
i don't have to suffer *as* much with webdev as i would if i made a website from scratch.

as an example, in zola, all blog pages, (and maybe someday my index page :P) are written in markdown. but so i can sort them, etc.
in the "blog" view that lists my pages, i have some metadata:
```toml
+++
title = "My New Website"
date = 2026-09-12
description = "i hate webdev"
[taxonomies]
tags = ["webdev"]
+++
```
that is the actual metadata for this blog post.
